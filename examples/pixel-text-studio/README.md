# Pixel Text Studio examples

These JSON files are deterministic starter treatments. They demonstrate the effect graph and are intentionally small enough to audit. Use them with a real reviewed bitmap font, then tune palette, spacing, effect depth and animation for the game instead of treating a starter preset as final art.

For 1990s-style work, review the result at its native authored resolution first. A one-pixel highlight, outline or spacing change can matter more than a large modern effect stack.
