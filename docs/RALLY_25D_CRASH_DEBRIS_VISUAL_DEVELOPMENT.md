# Rally 2.5D Crash Debris visual development

Art Studio compiles twelve individual transparent references for the vehicle Crash Debris family. The set covers front, rear and side impact direction, low and high impulse, wind response, four isolated particle roles and late decay.

The system keeps paint chips, metal shards, body-panel fragments and dust support visually separate. Large panels are deliberately sparse; dust may support the impact but cannot hide the origin or become a generic screen-filling cloud.

Every job produces one `2048 × 2048` PNG. The compiler binds the exact dependency graph, prompt, working path, master path, idempotency key and SHA-256 for each job. A submitted provider session is accepted only when it is the deterministic reconstruction of the retained specification.

The compiler plans provider work only. It cannot render images, approve creative candidates, assemble final textures, mutate downstream repositories, deploy or publish. Approved exact source bytes remain required before 3D Studio can use the references.
