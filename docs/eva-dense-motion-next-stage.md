# Next governed EVA stage

The source bridge ends with ten exact-byte `candidate.png` files and ten pairs of source inspection/materialisation receipts. The next stage is independent candidate assurance for all ten candidates.

That next stage must:

- bind each assurance to the exact v2 programme, job, candidate path and candidate SHA-256;
- require at least two independent inspectors for every required check;
- maintain the existing minimum confidence floor of 0.95;
- create no alpha matte, approval, upload, release or Runtime authority;
- preflight all ten candidate/receipt bindings before admitting any campaign-level success;
- reject any candidate whose bytes differ from the source materialisation receipt;
- keep the live three-frame fallback unchanged until the complete new ten-frame family is reviewed and atomically activated.
