`compileCouncilAvatarMediaReadiness()` is the fail-closed read/compute surface for the current four-seat Council media state. It does not replace the production programme, identity bootstrap, provider transactions, creative review, Runtime publication or website activation.

The governed Top Hat provider campaign exists, but repository state does not establish the required adapter selection, exact adapter SHA or six slot-specific time-bounded provider authorizations.

No real provider selection, admission, time-bounded authorization, execution receipt or approved identity master is established by repository state.

No real provider selection, admission, time-bounded authorization, execution receipt or approved identity master is established by repository state.

Three characters therefore have a provider execution surface available: Top Hat Man, Council Critic and Council Open Reviewer. Zero characters have established real provider execution evidence, and zero Council characters satisfy the complete 749-image authored-animation production gate. Generation never equals approval, and neither Runtime nor website activation is allowed from this readiness result.

## Character-identity provider boundary

The original Critic and Open Reviewer identities use:

- `scripts/compile-project-art-character-identity-provider-runtime.mjs` for explicit provider admission, one-shot authorization and exact runtime-adapter compilation;
- `scripts/run-project-art-character-identity-provider.mjs` for the actual durable provider transaction;
- exactly one provider/model allow-list entry per admitted job;
- no provider fallback;
- at most one provider call and one runtime attempt per authorization;
- authorization windows no longer than 24 hours;
- candidate-only intermediate artifacts and immutable evidence;
- no candidate, identity, animation, publication or activation approval by generation.

Each four-candidate-set campaign is continuity-bound. `full-body-right` must be generated first as the set anchor. `full-body-left` and `neutral-bust` may run only from the exact successful, still-unapproved `full-body-right` candidate artifact from that same set. The runtime re-verifies the immutable artifact before dependent execution and rejects cross-set anchor use.

## Agent and MCP use

The Council production MCP exposes `evavo_art_council_avatar_media_readiness`. It returns the deterministic stage, blockers, command surfaces and required next evidence for all four characters while retaining zero provider-selection, provider-admission, provider-authorization, provider-execution, approval, mutation, publication, deployment or activation authority.

Use `council-avatar-worker-stack` to validate the exact local six-repository estate before relying on readiness state for production planning. A provider execution surface being available is not evidence that a provider was selected or authorized and is not evidence that image bytes were generated.
