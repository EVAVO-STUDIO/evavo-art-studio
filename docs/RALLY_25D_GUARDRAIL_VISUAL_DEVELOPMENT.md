# Guardrail visual-development jobs

The modular guardrail kit is the next playable support asset after the road-sign family. It compiles twelve independent one-image jobs for straight, left-curve, right-curve and end-cap modules.

The source program preserves one shared beam profile, post spacing, spacer-block stack, fastener family, module length and connection system. It covers four identity images, four modeling/construction references, one dry/wet material reference and three progressive damage or detachable-component references.

Every job produces exactly one `2048 × 2048` PNG with its own deterministic SHA-256, idempotency key, dependency list, working path and master path. Isolated identity, orthographic and damage references use true transparency rather than contact sheets.

The specification forbids real authority branding, generated text, unrelated prop families, photogrammetry noise, baked directional shadows and multi-panel layouts. Provider execution, creative approval, image mutation, downstream repository writes, Git mutation, deployment and publication remain closed. Approved rendered bytes must still pass the established named-human and exact-byte admission boundary before 3D production.
