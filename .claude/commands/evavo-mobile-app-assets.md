# EVAVO mobile app assets

Use this command only with a verified `evavo.mobile-app-production-plan.v1`.

1. Compile the plan with `node scripts/compile-mobile-app-asset-plan.mjs --input <production-plan.json>`.
2. Preserve the complete app, brand, device, vendor, UX and safety context for every asset task.
3. Resolve and visually inspect every supplied full-resolution reference before provider planning.
4. Keep provider selection unassigned until the exact provider capability and execution admission are known.
5. Generate or edit only candidate assets inside the declared logical workspace.
6. Preserve immutable provider/source output and work on separate mastered copies.
7. Review full resolution, runtime scale, accessibility, alpha and hostile-background evidence as declared.
8. Package only the exact approved candidate digest for Development Studio.
9. Never write, commit or push the runtime repository from Art Studio.

Do not create generic AI-looking mobile art. Preserve EVAVO's actual wordmark construction, distinctive E and O, restrained black/white/cherry-red identity and the real application purpose.
