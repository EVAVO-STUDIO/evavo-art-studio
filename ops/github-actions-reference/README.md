# Inactive GitHub Actions reference archive

The YAML files below are preserved for historical and portability reference only. GitHub does not execute workflows outside `.github/workflows`, so this archive consumes no Actions capacity and is not part of the Art Studio validation path.

Do not treat these definitions as current operating authority. Local commands, package tests, the local quality gate and the checkout-local pre-push hook are authoritative. Restoring any archived workflow to `.github/workflows` requires an explicit budget decision, a security review, and a corresponding policy change.
